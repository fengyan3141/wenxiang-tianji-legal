# 问象天机 · 法务页面

问象天机（Wenxiang Tianji）App 的隐私政策、用户协议与数据删除说明，通过 GitHub Pages 公开托管。

- 隐私政策 `/privacy/`
- 用户协议 `/terms/`
- 删除你的数据 `/data-deletion/`（中文 / English）

**这个仓库只放构建产物。** 正文的唯一真源是主仓库 `wenxiang-tianji` 里的
`docs/PRIVACY_POLICY.md` 与 `docs/TERMS_OF_SERVICE.md`；改文案请改那两份，
然后在主仓库跑 `legal/publish.sh` 重新生成并推送到这里。手改本仓库的 HTML
会在下次发布时被覆盖。
